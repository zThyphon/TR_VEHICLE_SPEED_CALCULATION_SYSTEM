This application developed by Mustafa Doruk ÇİL with 
using YOLOv11, YOLOv8s and PaddleOCR. 

This application calculates speed of vehicles (car, motorcycle, bus, truck). 
If vehicle speed is more than assigned speed system saves the vehicle's plate
and its speed, plate, date and time detail.  

For Executing the Script
1) Download libraries in requirements.txt
2) Set traffic video path (assign 0 for using default camera)
3) Set speed calculation based options in config file
4) Execute main.py
